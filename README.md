# 🔐 File Integrity Monitor

A Python-based cybersecurity tool that monitors files and detects unauthorized changes using SHA-256 hashing.

## 🚀 Features

- 🔑 Generates SHA-256 hashes for files
- 📸 Creates a trusted baseline
- ⚠️ Detects modified files
- 🆕 Detects newly added files
- ❌ Detects deleted files
- 📝 Maintains logs of detected changes
- 🛡️ Includes risk assessment for file changes

## 🛠️ Technologies Used

- Python
- SHA-256 Hashing
- File Handling
- JSON
- Git & GitHub
